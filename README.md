# Table Flow - Patch Notes

I kept telling my players things — a house rule changed, a bit of lore became canon, the next session moved — and then telling them again, because the first time went into the group chat and died there.

Patch Notes puts the announcement in Foundry instead. I write it, I publish it, my players get a popup. If they say they never saw it, the popup was right there. That's the whole idea.

Part of the Table Flow suite. The other modules handle breaks and prep. This one handles the talking.

## What it does

**Library.** Save entries before you need them — title, body, done. Edit or delete them whenever. The Library button sits next to the entry box.

**Rich text bodies.** Entry bodies take basic HTML and Foundry content links, so you can link the journal entry, the actor, the thing everyone's arguing about.

**Popup header.** Set the popup's title and an optional subtitle. Pen icon next to Popup Header, edit, Save.

**Preview.** See exactly what your players will see, before they see it. Fewer regrets.

**Publish.** One click publishes the entry you're writing. Or tick several saved entries in the library and hit Publish Selected, for when you've been saving them up.

**Floating button.** A scroll button that opens the manager. Drag it wherever you want it. If Intermission is active, it docks underneath the Intermission button, because apparently my modules like each other.

## What players see

Published notes show up automatically — immediately if they're online, next time they load the world if they're not.

Each player sees a published set once. Closing it with "Got it!" (or the close button) marks it seen, so it won't nag them again.

They can reopen the current notes anytime from the floating button, which turns blue while there are unread notes. Blue means "you haven't read this yet." They know what they did.

## Installation

1. In Foundry, open Add-on Modules and click Install Module.
2. Paste this into the Manifest URL field and click Install:

   https://github.com/AvalloSolomov/Table-Flow-Patch-Notes/releases/latest/download/module.json

3. Enable Table Flow - Patch Notes in your world's module settings.

That's it. Your players install nothing.

## Usage

**If you're the GM:**

Click the scroll button (bottom-right by default) to open the manager.

Under New Entry, write a title and a body. Save to Library keeps it for later. Preview / Publish in the footer shows it to players right away — publishing also saves it to the library, so nothing gets lost.

To publish several saved entries at once: Library, tick the ones you want, Publish Selected. Pen and trash icons in there for editing and deleting.

The pen icon next to Popup Header changes the popup title and subtitle.

Two things worth knowing: publishing replaces the previously published set — the new set is the set. And deleting an entry removes it from the published set too, so if you publish something by mistake, deleting it actually unpublishes it.

**If you're a player:**

The popup appears when new notes are published. Click "Got it!" (or the close button) to dismiss it. Click the scroll button anytime to read the current notes again. That's genuinely all of it.
